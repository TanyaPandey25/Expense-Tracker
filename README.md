# 💰 Expense Tracker
A modern, lightweight, and responsive web application built with vanilla JavaScript, HTML5, and CSS3 to help you track your income, expenses, and overall account balance in real time

---

## ✨ Features
- **Dynamic Balance & Summary:** Automatically calculates total balance, incoming cash flow, and outgoing expenses.
- **Local Storage Integration:** Persists your transaction records securely in your browser's `localStorage` so data isn't lost on refresh.
- **Add & Remove Transactions:** Easily log new entries with custom descriptions and amounts, or delete records when needed.
- **Modern UI/UX:** Styled with smooth transitions, custom scrollbars, and visual indicators distinguishing income (green) from expenses (red).
- **Mobile-Friendly / Responsive:** Designed using CSS Grid and media queries to work seamlessly across desktops, tablets, and mobile devices.

---

## 🛠️ Built With
- **HTML5** – Semantic markup structure
- **CSS3** – Modern styling, CSS Grid, Flexbox, custom gradients, and animations
- **JavaScript (ES6+)** – DOM manipulation, event handling, array methods (`reduce`, `filter`), and `localStorage`

---

## 🚀 Getting Started
To run this project locally on your machine, follow these simple steps:
➡️Clone or Download this repository to your local device. 
➡️Ensure all three files (index.html, style.css, and script.js) are in the same directory. 
➡️Open index.html in any modern web browser (Google Chrome, Firefox, Safari, Edge).

---

## 💡 How to Use
- View Balance: Check your total balance and monthly/overall summary right at the top.   
- Add a Transaction:Enter a short description (e.g., "Salary", "Grocery Shopping").
- Enter the amount: use a positive value for income (e.g., 500) and a negative value for expenses (e.g., -45.50).
- Click Add Transaction.   
- Delete a Transaction: Hover over any item in the transaction list and click the x button to remove it.
